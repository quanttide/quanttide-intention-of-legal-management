# 算法备案：自己先走通的第一关

> 对外口径见 [brochure/compliance/algorithm.md](https://github.com/quanttide/quanttide-brochure-of-legal-management/blob/main/compliance/algorithm.md)。本文是内部意图记录。

## 意图

算法备案是我们自己的产品上线必经的监管关口，**第一优先级是自己过**。2026 年 10 月已走通：五步流程（判断 → 安全评估 → 属地提交 → 补正 → 拿号）、材料三层、五个会打回的坑，全部一手经验。

自己走通的沉淀都在仓里：

| 沉淀 | 位置 |
|------|------|
| 法规核实正本（条款级、带官网链接） | library（生成式人工智能备案/01） |
| 流程与材料清单 | library（02、03、04） |
| 官方模板原件 | library（templates/） |
| 主体责任基本情况成稿与口径参数 | profile（quanttide-agent/） |

## 推己及人

自己跑通过一次之后，这条路对别人是可复制的：材料有母本、坑有清单、法规有正本。将来谁要走，照着仓走——带人走是延伸，不是新生意。

## 下一步

补正与变更（模型迭代、功能变化都会触发）按仓里正本原样续，不重新编口径；第二个产品备案时验证这套流程的可复用性。
